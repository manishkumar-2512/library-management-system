# Library Management System

A simple **Library Management System built with Python**.

The project uses **JSON** to store and maintain book data between program runs.

## Features

* Add new books
* Remove books
* Search for books
* Display all books
* Display available books
* Borrow books
* Return books
* Update book information
* Count total, available, and borrowed books
* Prevent duplicate book codes
* Prevent removal of borrowed books

## Technologies Used

* Python
* JSON
* Object-Oriented Programming
* File Handling

## Project Structure

```text
library-management-system/

```

## How to Run

1. Clone the repository.
2. Open the project folder.
3. Run the Python program:

```bash
python library.py
```

The program automatically creates `library.json` if it does not already exist.
